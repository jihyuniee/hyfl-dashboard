# HYFL 야간자율학습 대시보드

Google Sheets의 QR 체크인 기록을 이용해 야간자율학습 출석 현황을 보여주는 Streamlit 앱입니다.

## 감독 좌석판

- 요일별 신청자 중 미체크인 지정석을 빨간색으로 표시
- 정상 체크인 좌석을 초록색으로 표시
- 지정석과 실제 체크인 좌석이 다르면 두 좌석을 주황색으로 표시
- 자유석은 비어 있을 때 흰색·빨간 굵은 테두리, 체크인 후 초록색으로 표시
- 사용 불가 좌석은 빗금으로 표시
- 1학년 2층과 2·3학년 4층을 구분해 조회
- 좌석 선택 시 학생·학번·지정석·실제 체크인 좌석·신청 요일 표시

## 초기 설정

Streamlit secrets에 기존 `gcp_service_account`와 함께 감독교사 PIN을 설정합니다.

```toml
supervisor_pin = "변경할 PIN"
```

좌석판의 `초기 데이터 설정`에서 아래 원본 파일을 한 번 등록하면, 앱이 같은 비공개 Google Spreadsheet에 `야자신청`과 `좌석설정` 워크시트를 생성합니다.

1. 야간 자기주도학습 참여조사 `.xlsx`
2. 자기주도학습 좌석배치표 `.xlsx`

원본 엑셀과 학생 개인정보는 GitHub 저장소에 저장하지 않습니다. 서비스 계정에는 대상 Spreadsheet 편집 권한이 필요합니다.
